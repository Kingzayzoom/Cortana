# Voice agents

The configuration of the three ElevenLabs agents, kept in the repo so it is reviewed like code. Each script applies its folder to the live agent; an edit made in the ElevenLabs dashboard is overwritten by the next apply.

| Agent                | Answers                      | Tools                                                               | Prompt                                 | Applied by                            |
| -------------------- | ---------------------------- | ------------------------------------------------------------------- | -------------------------------------- | ------------------------------------- |
| **Samantha**         | The browser voice round      | 20 client tools, run in the page ([tools.json](browser/tools.json)) | [browser/prompt.md](browser/prompt.md) | `scripts/configure-agent.mjs`         |
| **Samantha Phone**   | Calls the app places         | 19 webhook tools ([tools.json](phone/tools.json))                   | [phone/prompt.md](phone/prompt.md)     | `scripts/configure-phone-agent.mjs`   |
| **Samantha Inbound** | Calls to the Samantha number | 3 webhook tools, built in the script                                | [inbound/prompt.md](inbound/prompt.md) | `scripts/configure-inbound-agent.mjs` |

Why three: client tools need a browser, so phone agents use webhooks instead. And an inbound caller supplies no dynamic variables, while ElevenLabs refuses any conversation whose first message or tools need one, so the inbound agent's tools carry a constant guest marker rather than a signed session.

## Files

- `*/prompt.md` — only the fenced `text` block is sent; everything around it is for people.
- `browser/tools.json` — **generated** by `npm run agent:export` from the Zod schemas in `src/lib` (`validation/contracts.ts`, `context/tools.ts`, `prime/tools.ts`). Regenerate after changing a schema; don't edit by hand.
- `phone/tools.json` — the round, briefing and front desk tools are written by hand; the context and Prime tools in it are regenerated by the same command. `__PUBLIC_URL__` and `__TOOL_SECRET__` are filled in at apply time.
- `browser/knowledge.md` — **generated** by the same command from `src/lib/content/round.ts`. Attached to the browser agent as a knowledge document.

## Applying

Every script reviews by default and changes nothing until `--apply`. The ids of what it created are kept in `.cortana/` so a second run updates instead of duplicating.

```bash
npm run agent:export
node scripts/configure-agent.mjs --apply
node scripts/configure-phone-agent.mjs --url=https://your-app.example --apply
node scripts/configure-inbound-agent.mjs --url=https://your-app.example --apply
```

The live agents' model and voice are preserved. Full setup, including the carrier: [docs/phone-setup.md](../docs/phone-setup.md).
